# CONTENT.md: Prestruct

Voice, tone, and formatting for AI-first docs.

---

## Principles

- **Concise** - AI agents scan fast. Short sentences, clear headers.
- **Code-first** - Show, don't tell. Examples before explanation.
- **No fluff** - No marketing, no buzzwords. Just facts.
- **Agnostic** - Works for any app, any framework extension.

---

## Structure

1. **Quick Start** - Copy → Edit → Run. 3 lines max.
2. **Config API** - Full reference. One file shown.
3. **CLI** - Commands only.
4. **Architecture** - 1 diagram or paragraph.
5. **Stack** - Requirements.
6. **Read next** - AGENTS.md for gotchas.

---

## Formatting

- Use `backticks` for code, paths, commands.
- Use `export default {` for config examples.
- Use `///` comments for script extension points.
- Use tables for quick references.

---

## What to avoid

-Long paragraphs
- Marketing language ("powerful", "game-changing")
- Human-centric UI instructions
- Tutorial-style handholding
- Versioned changelogs (commit history is the source)
